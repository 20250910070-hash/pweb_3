PRE-TEST

1. Jelaskan keudukan CSS dalam pemrograman web?

Dalam pengembangan web ada tiga lapisan dengan tugas berbeda:

  1. HTML membentuk struktur dan isi halaman (judul, paragraf, gambar, tabel).
  2. CSS mengatur tampilan: warna, font, ukuran, jarak, tata letak, dan responsivitas
  3. JavaScript mengatur perilaku dan interaksi.

Jadi CSS berkedudukan sebagai bahasa penataan tampilan yang terpisah dari struktur HTML Pemisahan ini punya beberapa manfaat:

  1. Satu file CSS bisa dipakai banyak halaman, sehingga mengubah tampilan seluruh website cukup di satu tempat Kode HTML lebih bersih dan mudah dirawat.
  2. Tampilan bisa disesuaikan untuk berbagai ukuran layar (desktop, tablet, ponsel).
  3. Menghemat waktu saat merancang situs web.

a. selektor umur 
* {
    margin: 0;
    padding: 0;
}

b. Selektor sederhana (berdasarkan tag, id, dan class)
p { color: blue; }          
.kotak { border: 1px solid; } 

c. Selektor kombinasi (berdasarkan hubungan antar elemen)
div p {
    color: green;    
}

d. Selektor pseudo-class (berdasarkan keadaan elemen)
a:hover {
    color: orange;  
}

e. Selektor atribut (berdasarkan atribut dan nilainya)
input[type="text"] {
    border: 2px solid purple;
}

f. Selektor pseudo-elemen (bagian tertentu dari elemen)
p::first-letter {
    font-size: 30px;
    color: red; 
}

1. Buat masing masing satu contoh program untuk mengimplementasikan cara menulis css 

    a. CSS Inline
    CSS Inline adalah cara menulis CSS langsung pada tag HTML menggunakan atribut style
    Cara ini digunakan untuk mengatur tampilan pada satu elemen HTML secara langsung.
    contoh
    !DOCTYPE html;
html;
head;
    ;title;CSS Inline;/title;
;/head;
;body;
    ;h1 style="text-align: center; font-size: 32px;"Belajar CSS Inline/h1;
    ;p style="font-family: Arial; font-size: 18px;"Ini adalah paragraf dengan CSS inline./p;
;/body;
;/html;
    
     b. CSS Internal
     CSS Internal adalah cara menulis CSS di dalam tag style yang terdapat pada bagian head HTML.
     Cara ini cocok digunakan untuk mengatur tampilan satu halaman website.
     contoh
     !DOCTYPE html;
     html;
     head;
    title;CSS Internal;/title;
    style;
        h1 {
            text-align: center;
            font-size: 32px;
        }
        p {
            font-family: Arial;
            font-size: 18px;
        }
    /style;
/head;
body;
    h1;Belajar CSS Internal;/h1;
    p;Ini adalah paragraf dengan CSS internal./p;
/body;
/html;
     c. CSS External
     CSS External adalah cara menulis CSS pada file terpisah dengan ekstensi .css, 
     kemudian dihubungkan dengan file HTML menggunakan tag link. Cara ini lebih rapi dan mudah 
     digunakan untuk beberapa halaman website.
